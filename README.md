# Fit & Fuel – Fitness-Web-App

Schlanke Web-App für Handy-Browser (später PWA). Daten liegen nur lokal im Browser (localStorage).

## Starten
Doppelklick auf `index.html` – fertig. Kein Server, keine Installation nötig.

## Struktur
- `index.html` – Gerüst der App
- `css/style.css` – Design (Farben oben in `:root`)
- `js/data/uebungen.js` – Übungskatalog mit Anleitungen (hier neue Übungen ergänzen)
- `js/data/drills.js` – Basketball-Drills
- `js/data/essen.js` – Ernährungs-Orientierung und Ideen
- `js/planer.js` – Regeln für die Trainingsvorschläge
- `js/storage.js` – Speichern/Laden/Sicherung
- `js/erholung.js` – Regeln der Erholungs-Ampel
- `js/screens/` – ein Screen pro Datei
- `js/app.js` – Navigation und Klicks

## Stand
Schritt 2: Name, Tages-Check, Trainingsvorschläge (Calisthenics + Basketball), Ernährung.
Schritt 1: Eintragen (Basketball/Calisthenics/Sonstiges), Übungsbibliothek mit Anleitungen,
Erholungs-Ampel, Rekorde, Sicherung. Kein medizinisches Hilfsmittel.
